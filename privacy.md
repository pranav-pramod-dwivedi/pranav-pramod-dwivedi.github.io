## 2. Zero-Tracking Architecture

This website operates as a high-performance, privacy-preserving static publication hosted on Cloudflare Pages:

- No Tracking Cookies: No first-party or third-party cookies are set in your browser.

- No Advertising Pixels: There are zero advertising trackers, behavioral profiling tags, or cross-site tracking beacons.

- No User Analytics Profiling: We do not track keystrokes, mouse heatmaps, or fingerprint browser configurations.

- Hosting Diagnostics: Edge CDN servers (Cloudflare) process standard ephemeral HTTP requests (IP address, user agent, requested path) strictly for network security, rate limiting, and DDoS defense.
